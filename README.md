\# RC Aircraft Sizing



This project is a preliminary sizing tool for a low-cost radio-controlled aircraft.



It was originally developed in 2021 as part of an academic final-year engineering project, then reorganized and cleaned for GitHub publication.



The purpose of the project is to estimate the main geometric and mass properties of a small RC aircraft using simplified aerodynamic, stability, and structural assumptions.



\## Project Context



The original project was focused on the design and construction of a low-cost radio-controlled aircraft for educational and experimental purposes.



The code performs a simplified aircraft sizing loop where the aircraft mass affects the wing sizing, and the resulting geometry affects the final estimated mass. The process is therefore solved iteratively.



This repository should be seen as an academic engineering prototype, not as a certified aircraft design software.



\## Features



\- Air properties definition

\- Material density definition

\- Airfoil coordinate loading

\- XFOIL-based 2D airfoil polar generation

\- Wing sizing

\- Horizontal tail sizing

\- Vertical tail sizing

\- Fuselage estimation

\- Aircraft mass convergence

\- Finite-wing aerodynamic analysis

\- Induced drag estimation

\- Profile drag estimation from XFOIL polar data

\## Main Components



\### `aircraft/air.py`



Defines atmospheric and flight condition parameters such as air density, cruise speed, stall speed, and dynamic viscosity.



\### `aircraft/material.py`



Defines material properties used for mass estimation.



\### `aircraft/airfoil.py`



Loads airfoil coordinates and stores default airfoil properties.



Some default parameters are provided as fallback values. When XFOIL is available, aerodynamic properties can be recomputed from generated polar data.



\### `aircraft/xfoil\_runner.py`



Handles the communication with the external XFOIL executable.



It creates temporary airfoil files, sends commands to XFOIL, and generates polar files.



\### `aircraft/polar\_reader.py`



Reads the polar output generated by XFOIL and extracts aerodynamic coefficients such as angle of attack, lift coefficient, drag coefficient, and moment coefficient.



\### `aircraft/aero\_analysis.py`



Uses XFOIL polar data to create interpolation functions for aerodynamic coefficients.



It also includes the finite-wing aerodynamic analysis used to estimate the induced drag.



\### `scripts/run\_sizing.py`



Main script used to run the aircraft sizing calculation.



\### `scripts/check\_xfoil.py`



Utility script used to verify that the XFOIL executable is correctly connected to the project.



\### `scripts/prepare\_airfoil\_for\_xfoil.py`



Utility script used to convert and clean airfoil coordinate files into a format compatible with XFOIL.



\## XFOIL Requirement



This project uses the external XFOIL executable to generate 2D airfoil polar data.



XFOIL must be installed separately.



On Windows, the expected path is currently:



```text

C:\\Xfoil\\xfoil.exe

```



If your XFOIL executable is located somewhere else, update the path in `aircraft/xfoil\_runner.py`.



\## Important Aerodynamic Note



XFOIL is used for \*\*2D airfoil analysis only\*\*.



It provides airfoil polar data such as:



\- `Cl`

\- `Cd`

\- `Cm`



The drag coefficient obtained from XFOIL mainly represents the airfoil/profile drag.



The induced drag of the finite wing is not directly computed by XFOIL. It is estimated separately in the finite-wing analysis.



In simplified form:



```text

CD\_total = CD\_profile + CD\_induced

```



\## Installation



Clone the repository:



```bash

git clone https://github.com/Tampico0302/rc-aircraft-sizing.git

cd rc-aircraft-sizing

```



Install the required Python packages:



```bash

pip install -r requirements.txt

```



XFOIL is not installed through `pip`. It must be downloaded and installed separately as an external executable.



\## Preparing Airfoil Files for XFOIL



If you want to use your own airfoil coordinate file, place it in the `data/` folder using this format:



```text

x y

x y

x y

```



For example:



```text

data/my\_airfoil.txt

```



Then run:



```bash

python -m scripts.prepare\_airfoil\_for\_xfoil my\_airfoil

```



This will generate:



```text

data/my\_airfoil\_xfoil.dat

```



The generated file is formatted for XFOIL with the airfoil name on the first line, followed by cleaned coordinate points.



The expected XFOIL format is:



```text

AirfoilName

x y

x y

x y

```



\## Check XFOIL



To check if XFOIL is correctly connected, run:



```bash

python -m scripts.check\_xfoil

```



If successful, XFOIL should generate a polar file in the local working directory used by the project.



\## Run



From the project root, run:



```bash

python -m scripts.run\_sizing

```



The script performs the aircraft sizing loop and prints the estimated aircraft parameters, including wing, fuselage, horizontal tail, vertical tail, and final mass information.



\## Data Files



The `data/` folder contains airfoil coordinate files.



Example:



```text

ishii.txt

ishii\_xfoil.dat

naca0007.txt

```



The file `ishii\_xfoil.dat` is formatted for XFOIL, with the first line containing the airfoil name followed by coordinate points.



\## Limitations



This project uses simplified assumptions and should not be considered a professional or certified aircraft design tool.



Current limitations include:



\- simplified structural mass estimation

\- simplified fuselage mass model

\- simplified stability and tail sizing assumptions

\- dependency on XFOIL convergence

\- 2D airfoil data used as input for finite-wing approximations

\- no experimental validation included in the code repository



\## Academic Disclaimer
